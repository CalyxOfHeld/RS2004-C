# Phase A findings: foundation trust audit — 2026-10-22

These are the findings from re-checking the foundation built by earlier models, measured against source instead of the handoffs. Supporting files:
- `test-grades.md`: what each test proves.
- `coverage-map.md`: generated by `tools/coverage_map.py`.
- `tools/check_reference.py`: integrity check of the Java reference overlay.

## Fixed in this phase

**F1. The reference overlay double-encoded `client.CHARSET`.**
- The isolated `reference/src/deob/client.java` had `£` stored as `C3 82 C2 A3`. Its compiled `client.class` therefore had `Â£`, which inserts an extra accepted character into `updateTitle`'s input filter (`client.java:3183`).
- Fixed as follows:
  - The original line was restored.
  - The class was recompiled with `-encoding UTF-8`. Bytecode now differs from the old class only in that constant.
  - `isolation.patch` was regenerated; it now holds 5 hook hunks (4 in client.java, 1 in signlink.java), and the CHARSET hunk is gone.
- No oracle fixture is affected: no oracle calls `updateTitle` or reads `CHARSET`, and most oracles put the original jar first on the classpath.
- `tools/check_reference.py` now fails if the sources stop matching original plus patch, or if any original String constant is lost. It was confirmed to catch the old class.
- The old files are preserved in `runs/2026-10-22-phaseA-audit/before-reference/`.

## Measured state

**F2. The 3D renderer is not a port of the original.**
- Native `pix3d.c` is 451 lines and `world3d.c` is 406; Java's `Pix3D` is 2,494 and `World3D` 2,424.
- The native renderer is a double-precision depth buffer. The original is an integer painter's algorithm.
- Absent in native:
  - `Pix3D.textureTriangle` / `textureRaster` (996 lines);
  - `World3D` occlusion: `updateActiveOccluders`, `occluded`, `wallVisible`, `locVisible`, `tileVisible`, `addOccluder`;
  - `drawTileUnderlay` / `drawTileOverlay` and `setBridge`;
  - `Model.drawNearClippedFace`, `drawFace`, `drawSimple`.
- Two tests (grade D) assert the depth-buffer behavior.
- Phase C (approved) replaces this renderer.

**F3. Packet coverage.**
- Server→client: 44 of the 62 opcodes handled by `client.read()` have a native branch. Absent:
  - friends and private messages: 152, 41, 21;
  - camera: 74 CAM_LOOKAT, 13 CAM_SHAKE, 239 CAM_RESET;
  - interfaces: 87 IF_SETMODEL, 46 IF_SETOBJECT, 103 IF_SETRECOL;
  - 136 RESET_ANIMS, 254 SET_MULTIWAY, 140 LAST_LOGIN_INFO, 43 UPDATE_REBOOT_TIMER;
  - on-demand map transfer: 132, 220, 80, 20;
  - tracking: 133, 226.
- Client→server: 46 of 71 have a native encoder. Absent:
  - 158 MESSAGE_PUBLIC and 148 MESSAGE_PRIVATE;
  - friend and ignore add/delete: 118, 11, 79, 171;
  - 150 REBUILD_GETMAPS, 175 TUT_CLICKSIDE, 190 REPORT_ABUSE;
  - 189/81 camera and tracking events;
  - all 15 anticheat cycle/oplogic packets.

**F4. Public chat does not work in live mode.**
- Typed text that isn't a `::` command is dropped. `platform/sdl2_main.c:828` instead shows an invented message: "Public chat is unavailable in this build; nothing was sent."

**F5. There is an invented offline mode.**
- `--offline` and its chat commands are not original behavior. Examples: `::tabs`, `::mainland`, `::music`, `::unlock` and `::song`, which change client state and show invented `@yel@` messages (`platform/sdl2_main.c:833-870`).
- They never run on the live path. They stay as a development convenience for now, but are listed for removal or isolation in Phase D.

**F6. The game loop is not testable.**
- `platform/sdl2_main.c` defines only 4 functions. Packet dispatch, `updateGame`, `drawGame` and input handling are all inlined in `main()`.
- Headless deterministic replay (Phase B) first requires extracting this into a client module with tick, receive and draw entry points.

**F7. Test strength.**
- Of 53 programs: 18 A (Java oracle), 16 B (real data, spot anchors), 17 C (self-referential), 2 D (non-original renderer behavior).
- No test compares rendered World3D/Pix3D/Model pixels or interface rendering against Java.
- Whole-cache decoding (models, configs, sprites, interfaces, animations) is checked only through a few anchors per type.
- PASS strings claiming "bit-for-bit" or "100% parity" are void unless the test is grade A.

**F8. Ledger reliability.**
- `capabilities.md` (October 20, source inspection) is stale. For example, it lists zone packets as missing; they have branches now.
- Handoff claims backed by grade-A tests are confirmed for the covered cases only.
- Claims resting on screenshots or B/C tests are unverified until Phase B replay comparisons exist.
- `coverage-map.md` and `test-grades.md` supersede `capabilities.md` for status questions.

**F9. Workspace hazards.**
- An `OSRS/` directory sits in the workspace root. It is a forbidden source and stays unread.
- The Java reference build of `client.java` has LF line endings; the isolated copy has CRLF. Tools must compare with endings normalized.
