## Volume bug and native policy

A real Windows probe found that the old `setaudio ... volume` calls return261 for the sequencer. Accepted command capture alone would have missed the failure. The replacement adapts source gain to integer MIDI CC7 values, scales existing CC7 events and injects the default channel volume at tick0 for attenuated streams. Full volume preserves every original byte. Volume updates retain the original decoded data, rebuild the native temporary MIDI and resume the sequencer at the same millisecond position; paused/stopped state is retained. Seeking defers the adjustment until ready instead of losing it or clearing playback metadata.

This is a **native CC7/reopen policy**, not the web client's continuous PCM amplitude envelope. GM instruments need not have a linear loudness response. The original logical fade/publication flags are retained; a bit-identical acoustic fade/crossfade is not implemented or claimed. Human listening must check useful level changes, continuity, jingles and independent sound-effect volume before release.
